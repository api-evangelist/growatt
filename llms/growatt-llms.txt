# Growatt

> Growatt New Energy is a global manufacturer of solar PV inverters, energy storage systems, and smart energy management products. It operates the ShineServer / ShinePhone cloud monitoring platform and publishes a token-authenticated Open API (V1) for reading plant and device telemetry, retrieving historical energy data, and reading or writing inverter parameters for MIN (TLX) string inverters and SPH (MIX) hybrid inverters.

## APIs

- [Growatt Open API V1 docs](https://www.showdoc.com.cn/262556420217021/0): Official token-authenticated REST API for the ShineServer monitoring platform. Base URLs: https://openapi.growatt.com/v1/ (global), https://openapi-cn.growatt.com/v1/ (China), https://openapi-us.growatt.com/v1/ (US).

## Authentication

- Static account token sent in the `token` HTTP header on every request; issued from the Open API console at https://openapi.growatt.com/. See authentication/growatt-authentication.yml.
